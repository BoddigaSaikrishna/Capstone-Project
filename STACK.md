# Project Technology Stack

Here is the technology stack used in this project:

### **Frontend Framework & Language**
*   **React (v18.3.1)**: Component-based UI library.
*   **TypeScript (v5.5.3)**: Provides static typing for code safety and predictability.

### **Build Tool & Bundler**
*   **Vite (v5.4.2)**: A fast, modern frontend build tool used for local development and bundling.

### **Backend & Database**
*   **Supabase Database (PostgreSQL)**: Serves as the backend-as-a-service (BaaS), utilizing PostgreSQL database.
*   **@supabase/supabase-js (v2.57.4)**: JavaScript/TypeScript client library to interact with Supabase authentication and database services.

### **Styling & UI Components**
*   **Tailwind CSS (v3.4.1)**: Utility-first CSS framework for custom responsive styling.
*   **Lucide React (v0.344.0)**: Modern, clean vector icons.
*   **Recharts (v3.10.0)**: Charting library used for rendering analytics and dashboard visualizations.

### **Linting & Code Quality**
*   **ESLint (v9.9.1)**: Configured for code styling and standard React lint rules.
