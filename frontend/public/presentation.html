02. Motivation & Background

Problem Statement

"Modern software and AI engineering teams operate across fragmented, isolated toolchains—GitHub for code, Jenkins for builds, Docker/K8s for deployment, and MLflow for models. This creates high cognitive friction, delayed build visibility, and severe CORS cross-origin integration barriers."
⚠️

Siloed Tooling

No single dashboard linking Git commits, Jenkins builds, and ML accuracy metrics.

🔒

CORS Security Locks

Browser security blocks direct web calls to local CI/CD engines like Jenkins.

📡

Observability Delay

Lack of live 2.5s telemetry streaming for CPU, RAM, and API latency streams.

05. Technical Blueprint

System Architecture Flow

Client Presentation

React 18 + TypeScript

Tailwind CSS glassmorphic interface with Recharts telemetry stream.

Reverse Proxy Gateway

Vite Proxy (/jenkins-proxy)

Bypasses browser CORS restrictions by forwarding requests directly to localhost:8080.

Backend & Storage

Supabase PostgreSQL

Persists ML applications, model accuracy scores, and deployment histories.
